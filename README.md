## ⚡ Getting Started

### Clone Repo
git clone https://github.com/36-maulya/book_show_1.git  
cd book_show_1  

### Install Dependencies

Frontend  
cd client  
npm install  

Backend  
cd server  
npm install  

---

### Environment Variables

Create `.env` in server:

MONGO_URI=your_mongodb_uri  
JWT_SECRET=your_secret  
PORT=5000  

---

### Run Locally

Backend  
cd server  
npm run dev  

Frontend  
cd client  
npm run dev
